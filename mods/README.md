# Graphics-replacement mods (native runtime): sprites and backgrounds

`mods.list` names the mod directories to load, one per line. Each directory holds a `mod.txt` plus raw indexed art. Art is host memory only, so it costs no ROM, VRAM or BW-RAM. Mods change **rendering only**; game logic still runs from the ROM. `test_mods.py` (sprites) and `test_bg.py` (backgrounds) check that game state is identical with mods on and off, and that VRAM is never modified.

## Rules
```
rule actor NAME     # replace a whole actor (all objects matched below) with one animated frame
rule object NAME    # replace each matching object in place (projectiles, effects)
rule tiles NAME     # replace background tiles by content (tile pack), and/or recolour
```
Directives (one per line, `#` starts a comment):

| Directive | Meaning |
|---|---|
| `when ADDR == V` / `when ADDR != V` / `when ADDR in V1 V2 …` | Activate only while the 16-bit BW-RAM word at ADDR matches (offset from $40:0000). All `when` lines must hold. |
| `match palette P tiles LO HI` | Native objects to hide/replace: OBJ palette P, first tile LO..HI. |
| `art FILE W H name0 name1 …` | Raw 8-bit indices, frames concatenated (W×H each), with frame names. Index 0 = transparent. |
| `palette P c1 … c15` | Write BGR555 colors 1..15 into OBJ palette P every frame while active. |
| `draw_palette P` | Draw the art with palette P (default: the matched object's palette). |
| `actor X Y CAMX CAMY POSE` | (actor) BW-RAM words for world X/Y, camera X/Y, and the pose word. |
| `anchor AX AY` | (actor) Art pixel placed at the actor's origin. |
| `flip_invert` | (actor) Invert the facing derived from the native objects' H-flip. |
| `anim NAME dur:frame …` | Animation; `dur` in frames; `0` holds that frame (as the last step it stops looping). |
| `pose ANIM v1 v2 …` | (actor) Pose-word values that select ANIM. `default ANIM` covers the rest. |
| `play ANIM` | (object) Animation cycled by the global frame counter. |
| `offset DX DY` | (object) Extra offset from the matched object's position. |
| `tilepack FILE` | (tiles) `KTP1` pack: entries `bpp, FNV-1a hash of the original 8x8 tile, new tile words`. Each frame, every 2bpp/4bpp tile slot in VRAM is hashed; matches are drawn from the pack. Applies wherever the game uploads that tile, in any BG layer. |
| `cgram START w1 …` | Write BGR555 words into CGRAM before each frame. |
| `scope tiles` / `scope always` | (tiles) Default `tiles`: the rule's palette writes apply only while at least one of its own tiles is in VRAM, so a stage restyle can't recolour other stages or menus. `always` disables that. |
| `cgram_lines Y0 Y1 START w1 …` | Write them at the start of every scanline Y0..Y1, so they survive the game's mid-frame palette loads (the HUD). Scanline 1 = screen row 0. |

## Drawing order
An actor's frame is drawn on each scanline at the **first matched native object in OAM order**, using that object's priority. Sprite-vs-sprite order and BG layering therefore stay native. Any art rows extending past the native body are drawn after all sprites, at OBJ priority 2. Blinking or hidden native bodies stay hidden, because a replacement is only drawn while its native objects are present.

## Background workflow
1. **Dump** a scene from a fixture: `/usr/bin/python3 tools/bg_dump.py blaster dumps/blaster`. Each BG layer comes out as indexed PNG bands (one per mid-frame palette state), with a per-pixel source map and VRAM/CGRAM copies. Per-scanline register capture handles HUD splits and parallax.
2. **Repaint** `bgN-yA-yB.png` → `bgN-yA-yB.edit.png`. Keep it indexed with the same palette. Each 8x8 tile must keep its own palette's colours. Changing palette entries is allowed and becomes `cgram_lines` for that band.
3. **Import**: `python3 tools/bg_import.py dumps/blaster EDIT.png --out mods/NAME --name NAME [--when …] [--strict]` (needs Pillow). It rejects cross-palette pixels and reports conflicting edits of a repeated tile.
4. **Preview**: `/usr/bin/python3 tools/preview.py FIXTURE MODS_DIR out.png --scale 3`. It prints how many pixels differ from the unmodified game.
